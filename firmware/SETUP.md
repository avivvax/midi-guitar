# הוראות התקנה – קושחת MIDI Guitar ל-ESP32-S3

המסמך הזה מסביר איך לצרוב את הקושחה לגיטרה בעזרת Arduino IDE, איך לכוונן את הרגישות ואיך לחבר את הגיטרה לטלפון. לא צריך לקרוא או לשנות קוד, חוץ ממספרי הפינים אם החיווט שלך שונה (שלב 4).

כשהקושחה צרובה, הגיטרה מופיעה בבלוטות' בשם **MIDI Guitar**. כל פריטה על מיתר נשלחת לאפליקציה כהודעת MIDI.

---

## 1. התקנת תמיכה ב-ESP32 (פעם אחת)

1. פתח את Arduino IDE (גרסה 2.x).
2. **File → Preferences**. בשדה **Additional boards manager URLs** הדבק:
   ```
   https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
   ```
   ולחץ OK.
3. **Tools → Board → Boards Manager…**. חפש `esp32`.
4. התקן את **esp32 by Espressif Systems**, גרסה **3.x**. הקושחה נבדקה מול 3.3.12; אל תתקין 2.x.

## 2. התקנת הספרייה (פעם אחת)

1. **Tools → Manage Libraries…**
2. חפש `NimBLE-Arduino`.
3. התקן את **NimBLE-Arduino by h2zero**, גרסה **2.x** (נבדק מול 2.5.1).

זו הספרייה היחידה שצריך. **לא** צריך להתקין "BLE-MIDI" או "MIDI Library". הקושחה מממשת BLE-MIDI בעצמה.

## 3. פתיחת הקושחה

פתח את הקובץ `firmware/midi_guitar/midi_guitar.ino`. ייפתחו שלוש לשוניות:

- `midi_guitar.ino`: התוכנה עצמה. לא צריך לגעת בה.
- `config.h`: פינים והגדרות חומרה. **זה הקובץ היחיד שאולי תשנה.**
- `StrumDetector.h`: זיהוי הפריטות. לא צריך לגעת בו.

## 4. חיבורים (פינים)

ברירת המחדל, כפי שמוגדרת ב-`config.h`:

| מה | פין ב-ESP32-S3 |
| --- | --- |
| פיאזו מיתר 1 – **E נמוך** (המיתר העבה) | GPIO 1 |
| פיאזו מיתר 2 – A | GPIO 2 |
| פיאזו מיתר 3 – D | GPIO 3 |
| פיאזו מיתר 4 – G | GPIO 4 |
| פיאזו מיתר 5 – B | GPIO 5 |
| פיאזו מיתר 6 – **e גבוה** (המיתר הדק) | GPIO 6 |
| פיאזו ייחוס על גוף הגיטרה (אופציונלי) | GPIO 7 |

החיבור של כל פיאזו:

- הרגל החיובית לפין, השלילית ל-GND.
- נגד 1MΩ בין הפין ל-GND.
- דיודת הגנה מהפין ל-3.3V.

**אם החיווט שלך שונה**, שנה את המספרים בשורה הזו ב-`config.h`. הסדר הוא מיתר 1 עד מיתר 6:
```
static const uint8_t PIEZO_PINS[6] = {1, 2, 3, 4, 5, 6};
```

- **אין פיאזו ייחוס?** שנה את השורה `REF_PIN = 7` ל-`REF_PIN = -1`.
- **מותר להשתמש רק בפינים GPIO 1 עד 10.** אלה פיני ADC1. שאר פיני האנלוג (ADC2) לא עובדים כשהבלוטות' פעיל.

## 5. הגדרות הלוח ב-Tools

| הגדרה בתפריט Tools | ערך |
| --- | --- |
| **Board** | **ESP32S3 Dev Module** (תחת esp32) |
| **USB CDC On Boot** | **Enabled** אם הכבל מחובר לשקע שכתוב לידו **USB**. **Disabled** אם הוא מחובר לשקע **COM** / **UART**. |
| **PSRAM** | לפי הדגם שכתוב על המודול: N16R8 → **OPI PSRAM**, N8R2 → **QSPI PSRAM**. לא בטוח? **Disabled** תמיד עובד. |
| **Port** | הפורט שמופיע כשהלוח מחובר |

שאר ההגדרות נשארות בברירת המחדל.

**איזה שקע USB?** בכרטיסי ESP32-S3 יש לרוב שני שקעים. מומלץ השקע שמסומן **USB** (עם USB CDC On Boot = Enabled), כי הוא מעביר את הנתונים הגולמיים לאפליקציה בלי לאבד שורות. גם השקע **COM** עובד, אבל בפריטות חזקות חלק מהשורות הגולמיות עלולות ללכת לאיבוד. זה לא משפיע על הבלוטות'.

## 6. צריבה

1. לחץ על החץ **Upload**.
2. אם ההעלאה נכשלת עם "Failed to connect": החזק את כפתור **BOOT**, לחץ ושחרר את **RST** (או **EN**), ושחרר את BOOT. אחר כך לחץ שוב Upload.
3. אחרי שההעלאה הסתיימה, לחץ פעם אחת על **RST**.

## 7. בדיקה וכיוונון דרך ה-Serial Monitor

1. **Tools → Serial Monitor**. בפינה הימנית התחתונה בחר **115200 baud** ו-**New Line**.
2. מיד יתחיל זרם מהיר של מספרים: 6 או 7 מספרים בכל שורה, אחד לכל פיאזו, והייחוס אחרון. זה תקין. האפליקציה משתמשת בזרם הזה במצב USB.
3. כדי לראות הודעות קריאות, הקלד בשורה העליונה ולחץ Enter:
   ```
   raw 0
   ```
   הזרם ייעצר, ובמקומו תופיע שורה על כל פריטה, למשל:
   ```
   # hit string 3 vel 64 peak 1210
   # reject string 4 (neighbour louder: 1500 > 300)
   ```
   - `hit`: פריטה שזוהתה. `vel` הוא העוצמה (1–127).
   - `reject`: פריטה שנדחתה כי מיתר שכן או הגוף רעדו חזק יותר. זה תקין כשפורטים מיתר אחד והשכן רועד איתו.
4. פרוט כל מיתר בעדינות ואחר כך בחוזקה, ובדוק:
   - **פריטה עדינה לא נקלטת** → הורד את הסף של המיתר. לדוגמה, למיתר 3:
     ```
     th 3 80
     ```
   - **הוא נקלט בלי שנגעת בו, או פעמיים על פריטה אחת** → העלה את הסף:
     ```
     th 3 300
     ```
   - **אותו סף לכל המיתרים:** `th all 150`
   - **גם פריטה חזקה לא מגיעה ל-vel גבוה** → הורד את `fs`, למשל `fs 1800`. **כל פריטה מגיעה מיד ל-127** → העלה אותו, למשל `fs 3500`.
   - **הקשה על גוף הגיטרה מפעילה מיתרים** → ודא שפיאזו הייחוס מחובר. אפשר להחמיר עם `ref 1.5`.
   - **בסטרום מהיר מיתרים נבלעים** → הקל עם `nb 0.6` (ברירת המחדל היא 1).
5. בסיום הקלד `raw 1` כדי להחזיר את הזרם הגולמי.

כל שינוי **נשמר אוטומטית** בזיכרון הלוח ונשאר גם אחרי כיבוי.

| פקודה | מה עושה |
| --- | --- |
| `help` | רשימת כל הפקודות |
| `show` | הצגת כל ההגדרות הנוכחיות |
| `th 3 450` | סף למיתר 3 (מיתרים 1–6, או `all` לכולם) |
| `fs 2500` | העוצמה שנחשבת "מקסימום" (127) |
| `curve 0.7` | עקומת עוצמה: מספר קטן יותר = רגיש יותר לפריטות עדינות |
| `test 1` | שליחת פריטת ניסיון על מיתר 1 בבלוטות', בלי לגעת בגיטרה |
| `stats` | מצב החיבור, קצב הדגימה ומרווח הבלוטות' שהטלפון אישר |
| `reset` | חזרה להגדרות היצרן |

**טיפ:** עם `raw 1`, **Tools → Serial Plotter** מציג גרף חי של כל ששת הפיאזואים. כך רואים יפה כמה רעש יש וכמה חזקה כל פריטה.

**חשוב:** כשמשתמשים באפליקציה במצב **USB Serial** במחשב, צריך **לסגור** קודם את ה-Serial Monitor ואת ה-Serial Plotter. רק תוכנה אחת יכולה להחזיק את הפורט בכל רגע.

## 8. חיבור לטלפון (Chrome באנדרואיד)

1. ודא שהבלוטות' **והמיקום** בטלפון דולקים. Chrome צריך את שניהם כדי לסרוק.
2. **לא** צריך לצמד את הגיטרה בהגדרות הבלוטות' של אנדרואיד. מוטב שלא, כדי שהיא לא תהיה תפוסה.
3. פתח ב-**Chrome** את האפליקציה:
   **https://avivvax.github.io/midi-guitar/**
4. הקש על המסך פעם אחת כדי להפעיל את הסאונד.
5. בלשונית **חיבור** בחר **Bluetooth MIDI**.
6. בחלון שנפתח בחר **MIDI Guitar** ולחץ **התאמה** (Pair).
7. הסטטוס יהפוך ל"מחובר" (נקודה ירוקה), והפסים של מד האות יקפצו כשתפרוט.
8. עבור ללשונית **נגינה** ותנגן.

אפשר גם להוסיף את האפליקציה למסך הבית: תפריט ⋮ ב-Chrome ← **הוספה למסך הבית** / **התקנת אפליקציה**.

**אם MIDI Guitar לא מופיע ברשימה:**

- ודא שהלוח דלוק. ב-Serial Monitor הקלד `stats`. צריך להופיע `BLE advertising as "MIDI Guitar"`.
- אם הגיטרה כבר מחוברת למכשיר אחר (טלפון אחר, מחשב), נתק אותה משם. היא מתחברת רק למכשיר אחד בכל פעם.
- אם צימדת אותה בעבר בהגדרות הבלוטות' של אנדרואיד, מחק את הצימוד ("שכח מכשיר") ונסה שוב.

**בדיקה בלי לגעת בגיטרה:** כשהגיטרה מחוברת לאפליקציה, הקלד ב-Serial Monitor:
```
test all
```
צריך לשמוע אקורד מהטלפון.
